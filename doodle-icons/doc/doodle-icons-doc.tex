This package provides \LaTeX{} support for the \textsf{Doodle-Icons} project (\url{https://khushmeen.com/icons}).

\medskip

\hspace*{5mm}\fbox{\begin{minipage}{0.75\linewidth}{\emph{A set of 439 free CC0 License high-quality SVG/PDF icons for you to use in your web projects.}}\end{minipage}}

\medskip

To use \textsf{doodle-icons} in your document, include the package with |\usepackage{doodle-icons}|.

An icon can be accessed using the icon name. A list of all included icons with their respective \textit{page} can be found at the end of this document.

\medskip

The individual icons are provided as pages of a PDF and are ultimately loaded using the |\includegraphics| command from the |graphicx| package.

\medskip

Thanks to \textsf{priiduonu} for the tip with stroke color !

\section{Usage}

\subsection{Generic macro}

\begin{Verbatim}[frame=single]
\doodleicon[height=...,(d)strut=...]<includegraphics options>{name}
\end{Verbatim}

Key \texttt{[height=...]} can be:

\begin{itemize}
	\item \texttt{dauto} (by default): inline insertion with height/depth;
	\item \texttt{auto}: inline insertion with height/nodepth;
	\item \texttt{a length}: normal insertion with fixed height;
	\item \texttt{manuel height/depth}: normal insertion with fixed height/depth.
\end{itemize}

The keys \texttt{[(d)strut=...]} can be used to set the \textit{reference} box for dimension calculations.

\medskip

By default, icons are given with a small border (with fixed 196x196 size), so the given height is the height of the \textit{full} box, not the hight of the icons.

\medskip

Example: Inline{\setlength\fboxsep{0pt}\fbox{\doodleicon{bottle}}}version or inline {\setlength\fboxsep{0pt}\fbox{\doodleicon{bottle}}} version

\pagebreak

\subsection{Examples}

\begin{Verbatim}[frame=single]
%normal version: inline with automatic height/depth (from qX characters)
\doodleicon[height=dauto]{bottle} %or \doodleicon{bottle}
\end{Verbatim}

{\Huge q\doodleicon{bottle}X}

\begin{Verbatim}[frame=single]
%normal version: inline with automatic height/depth (from specified characters)
(q\doodleicon[height=dauto,dstrut=(qB)]{bottle}B)
\end{Verbatim}

{\Huge (q\doodleicon[height=dauto,dstrut=(qB)]{bottle}B)}

\begin{Verbatim}[frame=single]
%normal version: inline with automatic height (from X character) default version
\doodleicon[height=auto]{bottle}
\end{Verbatim}

{\Huge X\doodleicon[height=auto]{bottle}X}

\begin{Verbatim}[frame=single]
%normal version: inline with manual height/depth
\doodleicon[height={0.8em/-0.4em}]{bottle}
\end{Verbatim}

{\Huge qb\doodleicon[height={0.8em/-0.4em}]{bottle}Xz}

\begin{Verbatim}[frame=single]
%fixed height
\doodleicon[height=2in]{bottle}
\end{Verbatim}

\doodleicon[height=1.5in]{bottle}
