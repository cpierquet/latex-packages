# materialdesign-icons

> This package aims to provide "Material Design Icons" for LaTeX like fontawesome or simpleicons.

---

### Manual installation

If you want the latest version directly from this repository:

1. Download the [repository](https://github.com/cpierquet/latex-packages/tree/main/materialdesign-icons) (click *Code > Download ZIP*, or clone it).
2. Place `materialdesign-icons.sty` and `materialdesign-icons-*-all.pdf` in a directory where LaTeX can find it, for example:
   - **TeX Live / Linux**: `~/texmf/tex/latex/materialdesign-icons/`
   - **MiKTeX / Windows**: `C:\Users\<user>\AppData\Roaming\MiKTeX\tex\latex\materialdesign-icons\`
   - **macOS (MacTeX)**: `~/Library/texmf/tex/latex/materialdesign-icons/`
3. Refresh the filename database:
   - TeX Live: `mktexlsr` or `texhash`
   - MiKTeX: `initexmf --update-fndb`

---

## Quick start

```latex
\usepackage{materialdesign-icons}
```
